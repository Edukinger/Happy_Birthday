# Feliz cumpleaños, Kimo Manuel 🎂

Página web interactiva de cumpleaños hecha con HTML, CSS y JavaScript.

## Ver la página localmente
Abre `index.html` en tu navegador. Mantén los tres archivos principales en la misma carpeta.

## Publicar con GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html`, `styles.css` y `script.js` a la raíz del repositorio.
3. Entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
6. Espera a que GitHub Pages genere el enlace de tu página.

El archivo principal debe llamarse exactamente `index.html` y estar en la raíz del repositorio.
